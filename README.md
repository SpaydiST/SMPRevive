# SMPRevive

Плагин для Paper (Minecraft **26.3**, Java **25**) для хардкорного SMP: у игроков ограниченное число сердец, смерть отнимает сердца, а павшего игрока можно вернуть **на алтаре**, заплатив предметами. В комплект входят казино для выбора «платёжного» предмета, аллергия на сердца, сцена-ивент для встречи новичков и админ-меню.

- Автор: **macronux**
- Версия: 1.3.7
- Платформа: Paper 26.3 (`api-version: 26.3`), Java 25

## Возможности

### Сердца
- Игроки начинают с `start-hearts` сердец, максимум — `max-hearts` (жёсткий предел 512), минимум — `min-hearts`.
- При смерти игрок теряет сердца; они выпадают предметом «Extra Heart» (по умолчанию `HEART_OF_THE_SEA`). ПКМ по сердцу — съесть и получить максимальное здоровье.
- Первая смерть бесплатная (`free-first-death`).
- Когда у игрока остаётся минимум сердец, сердца больше не выпадают.

### Казино и платёжный предмет
- Каждый игрок выбирает в казино (слот-машина) **свой предмет для воскрешения** из `casino-pool` (алмаз, изумруд, золото, железо, незерит, лазурит, редстоун, аметист, медь, кварц).
- Казино открывается при первом входе и при приземлении новичка в ивенте. Администратор может открыть его командой `/reviveitem <игрок>`.
- Если игрок закрыл казино, не выбрав, остаётся предмет, выданный случайно.

### Алтарь воскрешения
- Алтарь — блок-маяк (`altar-block-material`) с кастомным отображением, ставится из предмета (`/revive giveblock` / `giveunbreak` для неразрушаемого).
- Чтобы воскресить игрока, нужно положить в алтарь его **голову** (в том числе полученную из креатива — платить придётся всё равно) и `tokens-required` его платёжных предметов.
- Воскрешение транзакционное: оплата и данные игрока записываются атомарно, при ошибке всё откатывается, а предметы возвращаются через журнал восстановления (`RecoveryJournal`).
- Можно воскресить и оффлайн-игрока: он появится у алтаря при следующем входе.
- Точка появления ищется безопасно в радиусе `spawn-radius` вокруг алтаря (в мирах с потолком, например в Незере, — под потолком).

### Аллергия на сердца
Админ может выдать игроку «аллергию»: сердца ему вредят, а при смерти его сердца защищены.

### Защита предметов и голов
Головы игроков и сердца защищены от потери (выпадение, воронки, взрывы, исчезновение). Данные хранятся с идемпотентными маркерами, которые автоматически очищаются через 60 дней.

### Ивент для новичков
Новые игроки ждут в лимбо-измерении `spaydiscore:limbo` (нужен плагин **SpaydisCore**), а затем появляются в сцене:

1. старые игроки собираются на месте ивента (`/event start`);
2. в небо поднимаются сердца, появляется белое облако;
3. новички «вылетают» из облака и приземляются, после приземления им открывается казино;
4. по желанию из облака вылетает **ТНТ-шлем** и надевается на случайного зрителя (нужен плагин **Toolkit**, иначе шлем не взрывается).

Дополнительно: `/event newbie particles x y z` — чёрные частицы плавно ведут каждого игрока к точке (подсказка, куда идти).

### Ритуал головы скелета и святилище визер-скелета
Положите **голову скелета** в слот головы алтаря и нажмите «Подтвердить» (оплата предметами не нужна):

1. голова вылезает из алтаря, взлетает на 10 блоков и медленно крутится;
2. из неё вылетают фиолетовые частицы и собираются в сферу, скрывающую череп; из сферы вылетает звезда Незера и зависает **над** сферой;
3. начинается шторм: вокруг бьют молнии (урона нет, слегка отбрасывает только тех, кто стоит в самом месте удара). Их становится всё больше, а радиус сужается, пока молния не ударит в голову;
4. у ближайшего игрока (в `ritual.donor-radius`, у кого больше минимума сердец) забирается одно сердце: оно зависает над ним и медленно летит к звезде;
5. звезда и сердце вместе опускаются на уровень сферы, расходятся и кружатся вокруг неё, встают друг напротив друга, между ними появляется белая нить, и радиус кругов сужается;
6. голова заменяется головой визер-скелета, чёрная сфера медленно исчезает, рядом появляется пара мобов.

Всё это время время в мире ускоряется (по умолчанию в 4 раза, во время грозы — в 300 раз, так что сменяются дни). Ускорение сделано по принципу плагина TimeSpeed; пока TimeSpeed сам перематывает мир, ритуал его не трогает. Настраивается в `ritual.time-*`.

Голова остаётся парить и медленно вращается, **переживая перезапуски** (хранится в `shrines.yml`). Из неё изредка падают адские частицы и звучат адские звуки, рядом редко появляются зомби-пиглины и зомби-хоглины, а в радиусе ±20 блоков по всем осям играет разный адский эмбиент.

Если ритуал прерван (перезапуск или сбой посередине), череп и забранное сердце возвращаются. Если ни у кого нет сердец сверх минимума, ритуал не начинается и череп не тратится.

Подсказка, куда класть голову: `/event skull x y z` ставит в точке светящийся полупрозрачный череп (модель из ресурспака, парит вверх-вниз и медленно крутится) и запускает ту же путеводную линию, что `/event newbie particles`. Как только начинается любой ритуал, череп и линия исчезают. Убрать вручную: `/event skull stop`.

Управление: `/revive shrine list` — список святилищ, `/revive shrine remove` — убрать ближайшее к вам.
### Админ-меню `/revive menu`
Сводка по игроку и серверу, воскрешение, ± сердца, выдача сердца/алтаря, аллергия, список игроков, история операций, диагностика, запуск ивента. История пишется в `admin-history.log` (ротация по 512 КиБ).

## Команды

Все команды требуют права `smprevive.admin` (по умолчанию — оператор).

| Команда | Описание |
| --- | --- |
| `/revive status [игрок]` | состояние игрока / сервера |
| `/revive menu [игрок]` | админ-меню |
| `/revive history [игрок\|all] [страница]` | история операций |
| `/revive diagnostics` | время работы тяжёлых задач, TPS |
| `/revive difficulty <easy\|normal\|hard>` | применить профиль сложности |
| `/revive reload` | перезагрузить конфиг и локали |
| `/revive giveblock <игрок>` / `giveunbreak <игрок>` | выдать алтарь / неразрушаемый алтарь |
| `/revive giveheart <игрок> [кол-во]` | выдать сердце |
| `/revive tokens <игрок>` | показать платёжный предмет игрока |
| `/revive sethearts <игрок> <кол-во>` | задать число сердец |
| `/revive revive <игрок>` | воскресить без оплаты |
| `/revive allergy <give\|remove\|list> …` | аллергия на сердца |
| `/revive shrine <list\|remove>` | святилища визер-скелета |
| `/reviveitem <игрок>` | открыть игроку казино |
| `/event start` / `preview` / `status` / `stop` | ивент |
| `/event newbie start x y z` | сцена встречи новичков |
| `/event newbie particles x y z` / `stop` | путеводные частицы |
| `/event skull x y z` / `stop` | полупрозрачный светящийся череп-маркер и путеводная линия |

Полный список с подсказками (tab-completion) доступен в игре.

## Профили сложности

| Профиль | Предметов для воскрешения | Резервный радиус ивента |
| --- | ---: | ---: |
| easy | 80 | 250 |
| normal | 160 | 500 |
| hard | 320 | 1000 |

Значения лежат в `admin-presets` файла `config.yml`. Установка плагина профиль сама не применяет — только команда `/revive difficulty`.

## Установка

1. Скачайте или соберите `SMPRevive-1.3.7.jar`.
2. Положите его в `plugins/` сервера **Paper 26.3** (Java 25).
3. Для ивента новичков установите **SpaydisCore**, для ТНТ-шлема — **Toolkit**. Опционально: **RandomSpawnPlus** (радиус спавна ивента).
4. Перезапустите сервер. Конфиг и языки появятся в `plugins/SMPRevive/`.

> Если обновляете плагин на сервере со старым `config.yml`, добавьте блок `event.tnt-head` вручную (см. ниже) — без него используются значения по умолчанию.

### Ресурспак
В папке [`resourcepack/`](resourcepack) лежит ресурспак с текстурами интерфейса алтаря и казино. Заголовки окон (`altar-title`, `casino-title`) используют специальные Unicode-символы битмап-шрифта из пака.

## Конфигурация (`config.yml`)

| Ключ | По умолчанию | Описание |
| --- | --- | --- |
| `default-locale` | `en_us` | язык сообщений в консоли и бродкастах (`en_us`, `ru_ru`) |
| `disabled-worlds` | `[]` | миры, где механики отключены |
| `min-hearts` / `max-hearts` / `start-hearts` | 5 / 20 / 10 | границы и старт |
| `tokens-required` | 160 | сколько предметов нужно для воскрешения (1–512) |
| `spawn-radius` | 15 | радиус появления вокруг алтаря (0–128) |
| `free-first-death` | `true` | бесплатная первая смерть |
| `default-gamemode` | `SURVIVAL` | режим игры после воскрешения |
| `casino-pool` | 10 материалов | возможные платёжные предметы |
| `casino-duration-ticks` / `casino-period-ticks` | 60 / 2 | анимация казино |
| `heart-material` | `HEART_OF_THE_SEA` | материал сердца |
| `altar-block-material` / `altar-item-material` | `BEACON` | блок и предмет алтаря |
| `altar-hitbox-material` | `BARRIER` | невидимый коллайдер под отображением |
| `altar-title` / `casino-title` | глифы пака | заголовки окон |
| `event.spawn-radius` | 0 | резервный радиус `/event start` |
| `event.tnt-head.enabled` | `true` | вылет ТНТ-шлема в сцене новичков |
| `event.tnt-head.radius` | 100 | радиус выбора зрителя |
| `ritual.donor-radius` | 64 | радиус поиска донора сердца |
| `ritual.storm-weather` | `true` | включать грозу на время молний (потом погода возвращается) |
| `ritual.mobs` | `true` | редкие мобы у святилища |
| `ritual.time-acceleration` / `time-speed` / `storm-time-speed` | `true` / 4 / 300 | ускорение времени во время ритуала и грозы |
| `admin-presets` | см. выше | профили сложности |

Тексты лежат в `lang/en_us.json` и `lang/ru_ru.json`, звуки — в настройках звуков плагина.

## Сборка из исходников

Требуется JDK 25. В репозитории есть Maven Wrapper.

```bash
./mvnw clean package          # Linux / macOS
build.cmd                     # Windows (запускает mvnw; JAVA_HOME должен указывать на JDK 25)
```

Готовый JAR: `target/SMPRevive-<версия>.jar`. Тесты (44 штуки) запускаются вместе со сборкой; они в том числе проверяют, что дескрипторы плагина и версия ресурспака согласованы.

> `maven-compiler-plugin` настроен с `<fork>true</fork>`: компиляция тестов внутри процесса Maven падает на JDK 25.
