# Проверка SMPRevive 1.2.0

Проверено 6 октября 2026. Реализация завершена, итоговая сборка и автоматические проверки успешны. Новые возможности требуют `smprevive.admin`, явно зарегистрированное в обоих дескрипторах с `default: op`.

Сборка использует Java 25 и Paper API 26.3.build.134-beta. Runtime проверялся на Paper 26.3-49-main@0fdc088, соответствующем присланному логу. Сервер скачан из официального API Paper, контрольная сумма проверена. Он слушал только 127.0.0.1:25637 и после проверок остановлен.

## Автоматические проверки

- 4 проверки истории: сохранение/повторная загрузка, фильтр UUID, предел 1000 записей, повреждённый хвост, ротация, ошибка записи и сохранение предупреждения после последующего успеха.
- 4 проверки команд: пустой массив Paper, допустимые позиции аргументов, независимость от локали сервера, запрет подсказок и BasicCommand без права администратора.
- 3 проверки атомарного файла: 1000 одинаковых сохранений дают 1 запись и 999 пропусков; изменение и откат сохраняются; удаление/внешнее изменение обнаруживаются; ошибка временного файла сохраняет оригинал и позволяет повторную запись.
- 14 существующих проверок механик, сборки, аллергии, событий, восстановления и совместимости v1.

Консольные проверки подтвердили статус известного UUID, отклонение неизвестного игрока и неверного числа сердец, запрет меню из консоли, фильтр истории, неправильную страницу и профиль, применение easy/normal, состояние/остановку неактивного события и диагностику. История сохранила операции предыдущего запуска. Две установки одинакового числа сердец дали 1 запись и 1 пропуск.

## Меню и 100 алтарей

Временный helper использовал реальные объекты инвентарей и событий Paper с proxy игрока. Проверены регистрация разрешения для операторов, отказ в открытии без разрешения, открытие администратору, расчёт недостающих 116 предметов при 44 алмазах и цене 160, 10 комбинаций кликов в верхнем/нижнем инвентаре, отмена перетаскивания и блокировка клика после отзыва разрешения. Финальный лог содержит ADMIN_MENU_PROXY_PASS.

Helper создал 100 алтарей в одном загруженном чанке, выполнил 100 проходов проверки кэша, сбросил ссылки и повторно сопоставил существующие сущности. Число отображений осталось 100, дубликатов нет. ALTAR_STRESS_PASS: 101 проход, среднее 0,553 мс, максимум 2,539 мс на данном ПК.

Это измерение без подключённых игроков и без сравнения с прежней версией; оно не доказывает ускорение на определённый процент. Полный сценарий события с участниками, нагрузка многих клиентов и визуальный вид меню на Minecraft-клиенте не проверялись. Тест сброса кэша не заменяет полный цикл фактической выгрузки чанка при игре. Pending tasks учитывает также временные отложенные задачи восстановления отображений.

## Независимая проверка

Luna explorer изучил потоки сохранения, возврата, интерфейсов и задач без изменений файлов. Sol 6.1 reviewer проверил отдельный снимок исходников. Корневой агент реализовал изменения и выполнил итоговые проверки. OpenCode и Antigravity доступны по doctor, но не запускались, их отчётов нет.

Три подтверждённых замечания исправлены:

1. Неполный хвост истории склеивался со следующей записью: добавлен разделитель; тест записывает и перечитывает файл после повреждённого хвоста.
2. Ошибка метаданных после замены файла оставляла неверный признак сохранённого состояния: он сбрасывается перед попыткой записи, метаданные читаются одним снимком; повторный откат действительно пишет файл.
3. Следующая успешная запись скрывала потерю предыдущей записи истории: предупреждение остаётся до конца запуска; тест проверяет отказ, последующий успех и перезапуск.

Reviewer не обнаружил других существенных ошибок в правах, защите инвентаря, профилях и совместимости v1.
