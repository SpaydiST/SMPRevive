# Алтарь SMPRevive 1.2.1

Сетка сдвинута вправо на один столбец. Номера слотов Bukkit начинаются с нуля:

| Ряд | Левый слот | Центр | Правый слот |
| --- | --- | --- | --- |
| Верхний | 12: оплата | 13: оплата | 14: оплата |
| Средний | 21: оплата | 22: голова | 23: оплата |
| Нижний | 30: оплата | 31: оплата | 32: оплата |

Подтверждение: единственный слот 49. Старые кнопки удалены из меню; закрытие обычной клавишей инвентаря возвращает содержимое через существующий механизм GuiEscrow.

Максимальная стоимость снижена с 576 до 512 (8 × 64). Значения выше 512 нормализуются при загрузке настроек; администраторские профили выше 512 отклоняются. Цена по умолчанию 160 не изменена.

При чтении кода прослежены открытие, разрешение кликов, получение головы, подсчёт оплаты, списание и возврат остатков: все используют общие новые номера слотов.
